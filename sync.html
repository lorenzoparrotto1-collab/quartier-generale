Sincronizzazione

Porta i tuoi dati da un dispositivo all'altro. Esporti tutto in un file, lo passi all'altro dispositivo (AirDrop, email, cloud) e lo importi. Cassaforte, radar e parete del colpo viaggiano insieme.

Esporta

Crea un file con tutti i tuoi dati di questo dispositivo. La cassaforte resta cifrata anche dentro il file.

Importa

Carica qui il file esportato da un altro dispositivo. I dati di quel file sostituiscono quelli attuali di questo dispositivo.

Sincronizzazione automatica

Per avere i dati allineati da soli, senza passare un file ogni volta, serve il tuo spazio Supabase. Quando avrai creato il progetto e mi darai Project URL e anon key, l'automatica comparira qui.
